# Aplikasi Klasifikasi Daun Herbal

Aplikasi untuk mengklasifikasikan 10 jenis daun herbal berdasarkan dataset menggunakan model MobileNetV2

## Teknologi yang Digunakan
- **Model / Training:** Google Colab (`.ipynb`)
- **Aplikasi Mobile:** Android Studio

## Cara Menjalankan
1. Buka proyek di **Android Studio**.
2. Sinkronkan dependensi Gradle dan jalankan aplikasi di emulator atau perangkat Android.
3. File hasil *build* (`.apk`/`.aab`) tersedia di menu **Releases**.
